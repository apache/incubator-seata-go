# Seata-go 2.2.0

Seata-go 2.2.0 版本变更说明。

Seata-go 是一个易于使用、高性能的开源分布式事务解决方案。

本版本更新内容如下：

## 新增特性（feature）：

- [[#1039](https://github.com/apache/incubator-seata-go/pull/1039)] 支持在 AT 模式下使用 QueryContext
- [[#1054](https://github.com/apache/incubator-seata-go/pull/1054)] 新增 RocketMQ 与 TCC 事务集成
- [[#1106](https://github.com/apache/incubator-seata-go/pull/1106)] 支持通过 Seata Naming Server 进行服务发现
- [[#1107](https://github.com/apache/incubator-seata-go/pull/1107)] 支持 Raft 集群的服务发现与 Leader 查找
- [[#1113](https://github.com/apache/incubator-seata-go/pull/1113)] 新增 Seata 客户端通信的 gRPC 传输支持
- [[#1117](https://github.com/apache/incubator-seata-go/pull/1117)] 支持通过 pgx 驱动在 XA 模式下使用 PostgreSQL
- [[#1118](https://github.com/apache/incubator-seata-go/pull/1118)] 支持在 AT 模式下使用 PostgreSQL
- [[#1125](https://github.com/apache/incubator-seata-go/pull/1125)] 完善 RocketMQ TCC 集成，支持主动结束消息事务与上报业务活动上下文
- [[#1126](https://github.com/apache/incubator-seata-go/pull/1126)] 新增服务发现 Provider 注册机制与地址存储
- [[#1133](https://github.com/apache/incubator-seata-go/pull/1133)] 完善复合主键处理并补充相关测试
- [[#1137](https://github.com/apache/incubator-seata-go/pull/1137)] 支持在全局事务中将 autoCommit 语句注册为 XA 分支
- [[#1138](https://github.com/apache/incubator-seata-go/pull/1138)] 将注册中心变更快照接入远程通信地址生命周期
- [[#1139](https://github.com/apache/incubator-seata-go/pull/1139)] 新增 ExecBatchContext 与 ExecBatchInTxContext，支持在同一本地事务内按顺序执行批次
- [[#1140](https://github.com/apache/incubator-seata-go/pull/1140)] 支持 AT 模式下的 MySQL 多语句 DML
- [[#1142](https://github.com/apache/incubator-seata-go/pull/1142)] 在 CI 中新增 RISC-V 构建检查

## 修复（bugfix）：

- [[#1065](https://github.com/apache/incubator-seata-go/pull/1065)] 修复列名包含转义字符时 undo_log 出现主键重复的问题
- [[#1070](https://github.com/apache/incubator-seata-go/pull/1070)] 保留协议头映射中值为空的键

- [[#1081](https://github.com/apache/incubator-seata-go/pull/1081)] 为一致性哈希负载均衡器的刷新操作增加同步保护
- [[#1083](https://github.com/apache/incubator-seata-go/pull/1083)] 在查询或执行失败时回滚自动创建的 AT 事务
- [[#1085](https://github.com/apache/incubator-seata-go/pull/1085)] 修复 TCC 防悬挂日志清理任务未取出缓存日志的问题
- [[#1091](https://github.com/apache/incubator-seata-go/pull/1091)] 修正 TCC 资源管理器的回退行为

- [[#1136](https://github.com/apache/incubator-seata-go/pull/1136)] 修复 MySQL 复合主键场景下的多值插入
- [[#1141](https://github.com/apache/incubator-seata-go/pull/1141)] 修正 AT 模式下 MySQL 批量执行、镜像与 undo-log 处理

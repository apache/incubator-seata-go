#### Seata-go 2.2.0

Seata-go 2.2.0 release notes.

Seata-go is an easy-to-use, high-performance, open source distributed transaction solution.

The version changes are as follows:

##### feature:

- [[#1039](https://github.com/apache/incubator-seata-go/pull/1039)] Add QueryContext support in AT mode
- [[#1054](https://github.com/apache/incubator-seata-go/pull/1054)] Add RocketMQ integration for TCC transactions
- [[#1106](https://github.com/apache/incubator-seata-go/pull/1106)] Support service discovery through Seata Naming Server
- [[#1107](https://github.com/apache/incubator-seata-go/pull/1107)] Support service discovery and leader lookup for Raft clusters
- [[#1113](https://github.com/apache/incubator-seata-go/pull/1113)] Add gRPC transport support for Seata client communication
- [[#1117](https://github.com/apache/incubator-seata-go/pull/1117)] Support PostgreSQL in XA mode through the pgx driver
- [[#1118](https://github.com/apache/incubator-seata-go/pull/1118)] Support PostgreSQL in AT mode
- [[#1125](https://github.com/apache/incubator-seata-go/pull/1125)] Extend RocketMQ TCC integration with active transaction completion and action-context reporting
- [[#1126](https://github.com/apache/incubator-seata-go/pull/1126)] Add a discovery provider registry and address store
- [[#1133](https://github.com/apache/incubator-seata-go/pull/1133)] Improve composite primary key handling and add related tests
- [[#1137](https://github.com/apache/incubator-seata-go/pull/1137)] Enroll autoCommit statements as XA branches in global transactions
- [[#1138](https://github.com/apache/incubator-seata-go/pull/1138)] Propagate registry change snapshots into the remoting address lifecycle
- [[#1139](https://github.com/apache/incubator-seata-go/pull/1139)] Add ExecBatchContext and ExecBatchInTxContext for ordered batch execution within one local transaction
- [[#1140](https://github.com/apache/incubator-seata-go/pull/1140)] Support MySQL multi-statement DML in AT mode
- [[#1142](https://github.com/apache/incubator-seata-go/pull/1142)] Add RISC-V build coverage to CI

##### bugfix:

- [[#996](https://github.com/apache/incubator-seata-go/pull/996)] Allow datasource background goroutines to exit gracefully
- [[#1061](https://github.com/apache/incubator-seata-go/pull/1061)] Implement commitOnXA() and LockQuery() behavior in XA mode
- [[#1065](https://github.com/apache/incubator-seata-go/pull/1065)] Fix duplicate primary key errors in undo_log when column names contain escaped characters
- [[#1070](https://github.com/apache/incubator-seata-go/pull/1070)] Preserve protocol header-map keys whose values are empty
- [[#1079](https://github.com/apache/incubator-seata-go/pull/1079)] Preserve distinct identities for TCC fence log entries
- [[#1081](https://github.com/apache/incubator-seata-go/pull/1081)] Synchronize consistent-hash load-balancer refresh operations
- [[#1083](https://github.com/apache/incubator-seata-go/pull/1083)] Roll back automatically created AT transactions when query or execution fails
- [[#1085](https://github.com/apache/incubator-seata-go/pull/1085)] Drain cached TCC fence logs for the cleanup task
- [[#1091](https://github.com/apache/incubator-seata-go/pull/1091)] Correct fallback behavior in the TCC resource manager
- [[#1096](https://github.com/apache/incubator-seata-go/pull/1096)] Propagate errors from AT executor before hooks
- [[#1102](https://github.com/apache/incubator-seata-go/pull/1102)] Fix the issue-translation bot workflow
- [[#1112](https://github.com/apache/incubator-seata-go/pull/1112)] Fix permissions and Node.js runtime settings for the issue bot workflow
- [[#1114](https://github.com/apache/incubator-seata-go/pull/1114)] Make DayValue serialization consistent across time zones
- [[#1123](https://github.com/apache/incubator-seata-go/pull/1123)] Intercept REPLACE INTO statements in AT mode
- [[#1135](https://github.com/apache/incubator-seata-go/pull/1135)] Align the RM undo-log deletion codec with the Java wire format
- [[#1136](https://github.com/apache/incubator-seata-go/pull/1136)] Fix MySQL multi-value inserts with composite primary keys
- [[#1141](https://github.com/apache/incubator-seata-go/pull/1141)] Correct MySQL batch execution, image and undo-log handling in AT mode
- [[#1150](https://github.com/apache/incubator-seata-go/pull/1150)] Correct the XA connection-hold fallback
- [[#1151](https://github.com/apache/incubator-seata-go/pull/1151)] Consolidate rowsWithStmt close handling to release query resources correctly
- [[#1166](https://github.com/apache/incubator-seata-go/pull/1166)] Use the correct gRPC message type for global commit requests
- [[#1170](https://github.com/apache/incubator-seata-go/pull/1170)] Align gRPC protobuf message types with the Seata protocol
- [[#1173](https://github.com/apache/incubator-seata-go/pull/1173)] Remove duplicate MySQL table-cache registration
- [[#1184](https://github.com/apache/incubator-seata-go/pull/1184)] Preserve undo errors and release resources on undo paths
- [[#1186](https://github.com/apache/incubator-seata-go/pull/1186)] Determine the configuration format from the last filename extension

- [[#1205](https://github.com/apache/incubator-seata-go/pull/1205)] Dispatch ConsistentHashLoadBalance and LeastActiveLoadBalance correctly, and fix related selection and counter handling

##### test:

##### doc:

- [[#1181](https://github.com/apache/incubator-seata-go/pull/1181)] Correct README installation commands and broken documentation links
